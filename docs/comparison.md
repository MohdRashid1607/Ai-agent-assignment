# Comparison Scorecard — Cloud Dev Environment + AI Agent (Levels 1–3)

Scoring method: 1 (poor) – 5 (excellent) per category, weighted score = score ÷ 5 × category weight.
Stacks compared: **Microsoft** (GitHub Codespaces + GitHub Copilot + Microsoft Foundry) vs **Google** (Cloud Workstations + Gemini Code Assist + Vertex AI Agent Builder) vs **AWS** (developer tooling + Amazon Q Developer + Bedrock AgentCore).

Note: the Microsoft stack was tested hands-on across all three levels (this repo). Google and AWS are evaluated from current official documentation only — no live account was provisioned for them.

## Weighted totals (score ÷ 5 × weight, summed)

- **Microsoft:** (5/5×15)+(5/5×15)+(4/5×15)+(4/5×15)+(5/5×10)+(3/5×10)+(4/5×10)+(4/5×10) = 15+15+12+12+10+6+8+8 = **86 / 100**
- **Google:** (4/5×15)+(3/5×15)+(4/5×15)+(4/5×15)+(4/5×10)+(3/5×10)+(3/5×10)+(3/5×10) = 12+9+12+12+8+6+6+6 = **71 / 100**
- **AWS:** (3/5×15)+(4/5×15)+(4/5×15)+(4/5×15)+(4/5×10)+(3/5×10)+(3/5×10)+(3/5×10) = 9+12+12+12+8+6+6+6 = **71 / 100**

## Recommendation

**Microsoft (GitHub Codespaces + GitHub Copilot + Microsoft Foundry) wins at 86/100**, driven mainly by categories that were *hands-on verified* in this prototype (developer experience, agentic coding capability, observability) rather than assumed. Google and AWS tie as runners-up at 71/100 each: Google's individual free-tier Gemini Code Assist IDE extension was deprecated on June 18, 2026 in favor of "Antigravity" (a genuine migration risk, not a guess), and AWS's tooling, while strong on agent runtime modularity (Bedrock AgentCore), is a less tightly unified developer-experience/DevOps story than GitHub's own ecosystem.

**Caveat / limitation:** Microsoft is the only stack tested hands-on. Google and AWS were scored from current official documentation, not live accounts. This is disclosed as a limitation, not hidden.

**Post-submission research note (not scored, for awareness only):** while researching current AWS pricing, both AWS Cloud9 and Amazon CodeCatalyst — AWS's browser-based dev-workspace products — were found to be closed to new customers as of November 2025. This wasn't factored into the AWS score above to keep this scorecard consistent with the version already presented in the demo video and slides; flagging it here as a fact worth knowing for any future re-evaluation.
